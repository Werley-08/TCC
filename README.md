# 📊 Avaliação de Modularidade em Arquiteturas de Software

## 📌 Sobre o Projeto

Este repositório contém o código em LaTeX do Trabalho de Conclusão de Curso (TCC) em Engenharia de Software, cujo objetivo é analisar o impacto de diferentes estilos arquiteturais na modularidade de sistemas orientados a objetos.

O estudo realiza uma comparação entre duas abordagens arquiteturais:

* Arquitetura em camadas (Layered Architecture)
* Arquitetura hexagonal (Hexagonal Architecture)

A análise é conduzida por meio da aplicação de métricas estruturais de software, com foco em atributos como acoplamento, coesão e estabilidade.

---

## 🎯 Objetivo

Avaliar a modularidade de sistemas orientados a objetos por meio da aplicação de métricas estruturais em diferentes estilos arquiteturais.

---

## 🧠 Contexto

A modularidade é um dos principais atributos de qualidade em software, influenciando diretamente aspectos como manutenção, evolução e compreensão do sistema.

Embora diferentes arquiteturas sejam amplamente utilizadas na indústria, muitas decisões ainda são baseadas em boas práticas e experiência, sem uma avaliação quantitativa clara.

Este trabalho busca preencher essa lacuna ao fornecer uma análise empírica baseada em dados reais.

---

## 📈 Resultados Esperados

* Comparação objetiva entre estilos arquiteturais
* Identificação de impactos na modularidade
* Apoio à tomada de decisão arquitetural baseada em métricas
